# Fey 小精靈

純 HTML / CSS / JavaScript Canvas 的像素風迷宮遊戲，可直接部署到 GitHub Pages。

## 操作

- 方向鍵 / WASD
- 手機或平板可用畫面上的方向鍵
- 「全螢幕」會依裝置比例放大遊戲畫面
- 遊戲中按 Space 暫停

## 隱藏彩蛋

在開始畫面輸入 `Google`（不分大小寫）會切換到 Google 紀念地圖風格變體；再輸入一次可解除。也支援 `ㄕㄟㄟㄕㄠㄍ`。

## 規則

豆子 10 分、能量豆 50 分；能量豆可讓幽靈進入易受攻擊狀態，被吃掉的幽靈 200 分。清空迷宮後進入下一關，速度逐關提升。共有 2 次額外生命機會。

本專案使用自行繪製的像素牆體、角色與迷宮變體，不直接引用原作遊戲圖片或 Google Doodle 素材。
